Setup Guide

Connect Google Sheets so results save automatically.

Step 1 — Create a Google Sheet

Go to sheets.google.com, create a new blank sheet, name it CSS Quiz Results. In Row 1 add these headers exactly:

Timestamp | Officer | Score | Total | Percent | Passed | WrongQuestions

Step 2 — Create the Apps Script

In your Sheet: Extensions → Apps Script. Replace all code with:

function doPost(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = JSON.parse(e.postData.contents); sheet.appendRow([data.timestamp, data.officer, data.score, data.total, data.percent + '%', data.passed, data.wrongQuestions]); return ContentService.createTextOutput(JSON.stringify({status:'ok'})) .setMimeType(ContentService.MimeType.JSON); } function doGet(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = sheet.getDataRange().getValues(); return ContentService.createTextOutput(JSON.stringify(data)) .setMimeType(ContentService.MimeType.JSON); }

Step 3 — Deploy & Paste URL

  1. Click Deploy → New deployment → Web app
  2. Execute as: Me | Who has access: Anyone
  3. Click Deploy, copy the Web App URL
  4. Open index.html, find GOOGLE_SCRIPT_URL near the top of the script and paste your URL
  5. Push to GitHub — done!
